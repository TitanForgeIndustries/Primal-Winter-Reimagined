# Winter Front

A server-side winter mod for Minecraft 1.20.1 Forge: cold biomes, configurable snowstorms and snow
accumulation. Clients do not need the mod; installing it adds optional fog, wind and snow effects.

Work in progress.

## Migrating from Primal Winter

Remove the old mod from the `mods` folder. Back up your world first: existing `primalwinter:snowy_*`
blocks and items are converted to their vanilla counterparts when the world loads.
